# EduMate - Intelligent E-Learning Platform with Chatbot Support 

EduMate is a modern, feature-rich online learning platform built with Next.js and MongoDB. It provides a seamless and interactive educational experience for students, instructors, and administrators. The platform is designed to be a complete solution for creating, managing, and enrolling in online courses, and it leverages AI for a personalized user experience.

## ✨ Key Features

-   **Role-Based Access Control (RBAC)**: Secure and distinct experiences for different user types.
    -   **Students**: Can browse courses, enroll, view course materials, submit assignments, take quizzes, and track their progress.
    -   **Instructors**: Can manage the content of their assigned courses, including lectures, assignments, and quizzes. They can also view student progress, grade submissions, and post announcements.
    -   **Administrators**: Have full oversight of the platform, including user management, course creation and assignment, category management, and viewing platform-wide analytics.

-   **Complete Course Lifecycle Management**:
    -   Admins can create, edit, and delete courses, manage course categories, and assign instructors.
    -   Instructors can add and manage rich course content, including lectures (from YouTube, PDF, or external URLs), assignments, and interactive quizzes.

-   **Secure Student Enrollment**:
    -   A straightforward payment and enrollment workflow. Students submit a payment request with transaction details, which an admin must approve.
    -   Users can see the status of their enrollment (pending, approved).

-   **Interactive Learning & Progress Tracking**:
    -   **Quizzes**: Instructors can create multi-choice quizzes to assess student understanding. Students can take quizzes and receive immediate feedback on their scores.
    -   **Assignments**: Instructors can create assignments with detailed instructions. Students can submit their work (via URL or file upload), and instructors can view submissions and provide grades.
    -   **Student Dashboard**: Students get a personalized dashboard to see their enrolled courses and pending enrollments.

-   **Certificate Generation**: Upon successful completion of all required coursework for a course marked as 'completed' by an admin, students can download a verifiable PDF certificate. Each certificate includes a unique verification ID and QR code.

-   **AI-Powered Recommendations**: The homepage features a section with personalized course suggestions for users, generated by an AI model based on their (mocked) browsing history and enrolled courses.

-   **Integrated Chatbot Support**: An integrated chatbot assists users with frequently asked questions about the platform, with a dedicated admin interface for training the chatbot's knowledge base.

-   **Comprehensive Admin Dashboard**: A central hub for administrators with key metrics and analytics, including:
    -   Totals for students, instructors, and courses.
    -   Platform-wide revenue.
    -   Charts for monthly enrollments and revenue.
    -   A list of pending instructor applications for approval or rejection.

## 🚀 Tech Stack

-   **Framework**: [Next.js](https://nextjs.org/) (with App Router and Server Components)
-   **Language**: [TypeScript](https://www.typescriptlang.org/)
-   **UI**: [React](https://reactjs.org/)
-   **Styling**: [Tailwind CSS](https://tailwindcss.com/) with [ShadCN UI](https://ui.shadcn.com/) for a modern, component-based design system.
-   **Database**: [MongoDB](https://www.mongodb.com/) with [Mongoose](https://mongoosejs.com/) for object data modeling.
-   **Authentication**: [JSON Web Tokens (JWT)](https://jwt.io/) for secure, stateless authentication managed via HTTP-only cookies.
-   **Generative AI**: [Google's Genkit]for the AI-powered course recommendation feature.
-   **PDF Generation**: `jsPDF` and `html2canvas` for client-side generation of course completion certificates.

## 📁 Project Structure

The project follows a standard Next.js App Router structure:

```
/src
├── app/                  # Main application routes
│   ├── (auth)/           # Route group for auth pages (login, register)
│   ├── (main)/           # Main app layout and pages
│   ├── admin/            # Admin-specific routes and dashboard
│   ├── api/              # API route handlers
│   ├── instructor/       # Instructor-specific routes
│   └── ...
├── components/           # Reusable React components (UI and client logic)
│   └── ui/               # Unstyled components from ShadCN
├── hooks/                # Custom React hooks
├── lib/                  # Helper functions, DB connection, static data
├── middleware.ts         # Handles authentication and route protection
├── models/               # Mongoose schemas for MongoDB collections
└── scripts/              # Standalone scripts for seeding DB, etc.
```

## 🛠️ Getting Started

Follow these instructions to get the project up and running on your local machine for development and testing.

### Prerequisites

-   [Node.js](https://nodejs.org/) (v18 or newer recommended)
-   [npm](https://www.npmjs.com/) or [yarn](https://yarnpkg.com/)
-   A MongoDB database instance (local or cloud-hosted, e.g., [MongoDB Atlas](https://www.mongodb.com/cloud/atlas))

### Installation

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/noOne-33/EduMate.git
    cd edumate
    ```

2.  **Install dependencies:**
    ```bash
    npm install
    # or
    yarn install
    ```

3.  **Set up environment variables:**
    Create a file named `.env` in the root of the project and add the following variables:

    ```env
    # Your MongoDB connection string
    MONGODB_URI=mongodb+srv://<user>:<password>@<cluster-url>/<database-name>?retryWrites=true&w=majority

    # A strong, secret key for signing JWTs (e.g., generate one with `openssl rand -base64 32`)
    JWT_SECRET=your-super-secret-key
    ```

### Running the Application

1.  **Seed the database:**
    This script will clear and populate the database with initial sample data for courses, categories, lectures, and assignments. It's safe to run multiple times as it preserves `users` and `enrollments`.
    ```bash
    npm run db:seed
    ```

2.  **Run the development server:**
    ```bash
    npm run dev
    ```
    The application will be available at [http://localhost:9005](http://localhost:9005).

## ⚙️ Available Scripts

-   `npm run dev`: Starts the Next.js development server with Turbopack.
-   `npm run build`: Builds the application for production.
-   `npm run start`: Starts a production server.
-   `npm run lint`: Runs ESLint to check for code quality.
-   `npm run db:seed`: Clears and seeds the database with initial data.
-   `npm run db:make-admin`: Assigns the 'admin' role to a specific user (edit email in `scripts/make-admin.ts`).

## 🔮 Future Improvements

While EduMate is a robust platform, there's always room for growth. Here are some potential features for future development:

-   **Real-time Notifications**: Implement a system (e.g., using WebSockets) to notify students of new announcements or when an assignment has been graded.
-   **Direct Messaging**: A chat system for students to communicate directly with their course instructor.
-   **Advanced Course Content**: Support for uploading video files directly, and embedding other types of rich media.
-   **More Payment Options**: Integrate Stripe or other payment gateways to automate the enrollment process.
-   **Student Reviews and Ratings**: Allow students to leave reviews and ratings on courses they have completed.
-   **Dark Mode**: Add a theme toggle to switch between light and dark modes for better user accessibility and preference.
